ii Photos 相册修复覆盖包

解压到项目根目录，按同名路径覆盖。基于本次 ii 工作目录，包含之前已经完成的修改。

- 在 Photos 引入角色、WVS 官号或未披露的 X 副号后才接入相册；未引入时自动发图先显示文字描述，生图需手动点。
- 已引入账号可选“仅匹配相册”或“先匹配，缺图可手动生图”；没有自动生图。图片 API 中的提示词、角色绑定和参考图设置沿用原实现。
- Photos 按传图、生图展示；生图自动归档并标来源；专用池仍用每批四张的共同识图流程。
- 可多角色关联、命名系列、拖放或在详情选择套图封面；使用记录、灰度暂锁和手动放出在详情可查。
- 同一图片的使用记录由各相册共享；Chat/朋友圈/Lysn/完全披露的 X 副号走私人组，WVS 艺人号/X 主号走公开组；WVS 官号专用，未披露的 X 副号独立。

安装后建议先在 Photos 不引入角色验证文字卡，再引入一位角色分别验证严格模式和手动生图。此环境缺少 node_modules，未执行 Next/TypeScript 构建。
