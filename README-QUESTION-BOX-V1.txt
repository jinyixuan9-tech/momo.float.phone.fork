提问箱 v1 · ii-phone 覆盖更新包

适用：此前已经应用 theqoo v2 / v2.1 覆盖包的 ii-phone 项目。
使用：解压到项目根目录，允许同路径文件覆盖，然后照常构建或部署。不要把 zip 当作独立插件导入。

功能：
- 桌面新增「提问箱」图标；已有自定义桌面自动补入图标。
- 每期开启 3 小时 / 1 天 / 3 天 / 自定义 1–720 小时。可选 U 和任意 C，或随机抽取指定人数的 C；开启后参与者固定。
- 每次刷新选择 1–5 道；开放期内重访也会按时间间隔收一批，不会一次补齐所有错过的批次。
- 陌生人向 U/C 提问，C 也可向 U 实名或匿名提问；U 可对参加本期的 C 实名或匿名提问。提问正文一律中文。
- U 手写自己的回答；C 的回答只有点击「让 TA 回答」才会调用文字 API。外国 C 原话加中文翻译；不完整的译文会提示重试。
- 到期停止收题及回答，未回答标记「已过期 · 未回答」；每期所有问题和回答留在往期记录。可以删除问题。
- 使用小手机现有文字 API 绑定；提问箱不使用 theqoo 专属翻译 API。

注意：当前所用源码底包中已有电话图标和入口引用，却没有 components/phone/phone-app.tsx。本包把这个缺文件的入口显示为原有占位页，以保证项目可以编译。如果你已有独立完成的电话 App，请先保留其 desktop-shell.tsx 中电话分支，再合并本包的提问箱入口和图标迁移，避免覆盖电话功能。

验证：TypeScript 类型检查通过；Next 生产构建通过。
